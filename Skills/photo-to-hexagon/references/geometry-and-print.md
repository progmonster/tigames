# Геометрия, размеры, квадратные карточки

## Физический размер

`across-flats` — между внешними краями противоположных сторон.
`across-vertices` — между внешними противоположными вершинами (большая диагональ).
Df = Dv × cos(30°).

Обводка включена в размер. При её толщине t внешний апофем a = Df/2 или
Dv×cos(30°)/2. Апофема пути рамки a−t/2; соединения miter сохраняют правильный
наружный шестиугольник, внутренняя граница имеет апофему a−t. Модели остаётся
a−t−clearance. Нельзя просто вычесть t из большой диагонали: вершины выступают
дальше, чем половина толщины. В SVG рамка имеет `fill="none"`.

Модель масштабируется равномерно относительно найденного центра. Зазор по
умолчанию 0,03 мм служит раздельной читаемости линий; `--clearance-mm 0` убирает
его. `--border-mm` задаётся в мм, независимо от исходных пикселей.

## Приближённый минимум

Кривые вектора адаптивно аппроксимируются ломаной с контролем ошибки; затем
вычисляется выпуклая оболочка. Для угла θ нормали сторон n_k имеют направления
θ+kπ/3. Минимизируется r по переменным центр c и апофема r:

    max(n_k · p) − n_k · c ≤ r, k = 0…5.

При фиксированном угле это линейная задача. Перебор [0°,60°) с шагом 0,5° и
уточнение лучших кандидатов дают численное приближение, не доказанный глобальный
минимум. Допуск аппроксимации добавляется как запас к r. Проверка после
масштабирования подтверждает попадание в рамку с этим запасом.

Не заменять геометрию прямоугольником PNG, не скрывать выходы обрезкой.
Подбор включает поворот рамки и смещение центра. Модель не деформируется.

## A4 и квадраты

Сторона квадратной карточки = max(ширина, высота внешней рамки) + 2×отступ.
По умолчанию отступ 3 мм, поля A4 10 мм. Рамка центрирована в квадрате.
Книжный A4: columns = floor((210−2×margin)/card), rows = floor((297−2×margin)/card).
Для альбомного страницы ширина и высота меняются местами.

Это обычная сетка, центрированная на листе, без поворотов отдельных карточек,
сотовой укладки и оптимизации плотности. Пунктирные линии разрезания общие
для соседей, рисуются один раз и существуют только в PDF. `--no-cut-guides`
отключает их. `--copies N` задаёт количество в пределах ёмкости одного листа;
по умолчанию заполняется вся сетка. Для большего количества печатай копии листа.

Если карточка не помещается, завершить с ошибкой без уменьшения размера.
Белая страница в PDF-просмотрщике — бумага; это не белая заливка SVG/PNG.
Печатать A4, 100% / «Фактический размер», без «Вписать». Проверять линейкой
именно заданное измерение: горизонтальный габарит повёрнутой рамки может
отличаться и от Df, и от Dv.
