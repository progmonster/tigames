# TiGames

Фабрика контурных иллюстраций конструктора: фото → чёрные контуры → настоящий
SVG в почти минимальном правильном шестиугольнике → PNG и квадратные карточки PDF A4.

Открой эту папку как проект и попроси, например:

> Используй $photo-to-hexagon. По приложенной фотографии создай модель
> в шестиугольнике 34 мм между противоположными сторонами. Подготовь SVG,
> прозрачный PNG и A4 с квадратными карточками для вырезания.

Или укажи «34 мм между противоположными вершинами» — это другой размер.
Размер рамки включает её обводку. Поля листа и отступы карточек можно указать в запросе.

## Подготовка окружения

Из корня проекта: `uv sync`. На компьютере нужна системная библиотека Cairo
(для SVG/PDF); на этом Mac используется установленная Homebrew-версия.
Работа с фото выполняется агентом через доступный инструмент изображения.
Скрипт принимает уже созданный/одобренный контурный рисунок, а не исходное фото.

```bash
.venv/bin/python .agents/skills/photo-to-hexagon/scripts/build.py \
  --lineart examples/technic-reference/approved-lineart.png \
  --size-mm 34 --measure across-flats \
  --output-dir outputs/my-model
```

Основные файлы результата: `model-outline.svg`, `model-outline.png`, `sheet-a4.pdf`.
Параметры и проверки находятся в `manifest.json`; временные файлы — в `work/`.
Контрольные PNG имеют цветную подложку только для просмотра прозрачности.

A4 содержит обычную сетку квадратов, без плотной сотовой укладки. По умолчанию
поля 10 мм, отступ в квадрате 3 мм и тонкие пунктирные линии разрезания.
Число карточек зависит от размера рамки и её оптимальной ориентации относительно модели.
Печатать **100% / «Фактический размер»**, без «Вписать в страницу».

Проверка помощника: `.venv/bin/python -m unittest discover -s tests -v`.
Полные агентские инструкции: `AGENTS.md`, навык: `.agents/skills/photo-to-hexagon/SKILL.md`.
